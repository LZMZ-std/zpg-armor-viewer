# ZPG Armor Viewer

Офлайн-примерочная брони для работы с текстурами PSD, PNG, JPG и WebP.
На Windows запусти `ArmorViewer.exe`. Для окна приложения используется установленный Edge или Chrome.

Кликни по детали, чтобы подключить текстуру. Меню «Детали» позволяет выбрать отсутствующее снаряжение.
Сохраняй правки поверх подключённого файла. Для PSD используй RGB, 8 бит на канал и максимальную совместимость.

## Сборка на Windows

Нужны Node.js, Python 3.11+ и компилятор .NET Framework 4.x из Windows.
Установи зависимости командой `npm install`, затем выполни `npm run build:windows`.

Модели и штатные текстуры основаны на ресурсах Legion Studios. Лицензия Three.js находится в `assets/vendor/three/LICENSE`.
